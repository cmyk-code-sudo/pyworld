# PyWorld

A Python library for interactive gaming with Chinese NLP chat, UI systems, and Android support.

## Features

- 🎮 Game engine integration
- 💬 Chinese Natural Language Processing and chat system
- 🎨 Advanced UI framework
- 📱 Full Android support
- ⚡ C language core module with high performance
- 🔧 Easy-to-use Python API

## Installation

```bash
pip install pyworld
```

## Quick Start

```python
from pyworld import Game, ChatBot, UI

game = Game()
chat = ChatBot(language='zh')
ui = UI()

response = chat.talk("你好")
print(response)

game.run()
```

## System Requirements

- Python 3.7+
- Android 5.0+ (for mobile devices)
- Supported platforms: Windows, macOS, Linux, Android
